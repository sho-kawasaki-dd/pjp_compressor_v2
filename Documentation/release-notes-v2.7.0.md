# v2.7.0 - 動画圧縮対応

PDF・JPEG・PNGのフォルダ一括圧縮に、H.264動画圧縮を追加しました。Windows x64向けインストーラーのビルド日は2026年11月2日です。

> 公開準備中: このノートの作成時点では、GitHubへのpush、タグ作成、Release作成、アセットのアップロードは行っていません。以下の配布前チェックを完了してから公開してください。

## 実装内容

### 動画圧縮

- `.mp4` / `.mov` / `.avi` / `.mkv` / `.webm` / `.wmv` / `.m4v` の入力に対応。出力はH.264（libx264）のMP4です。
- 品質、速度プリセット、音声処理、長辺リサイズを設定できます。
- 最初のカバーアート以外の本編映像、全音声・全字幕、および言語・既定選択・チャプター・表示向き・対象メタデータを可能な範囲で保持します。追加映像・カバーアートは保持対象外です。
- 音声の既定はコピーです。AAC / MP3 / AC-3 / E-AC-3 / ALAC / FLAC以外は、該当トラックのみAACへ変換してログに通知します。「音声なし」も選択できます。
- H.265/HEVCのエンコード・デコードは行いません。HEVC映像ストリームを含む入力は、ffprobeで情報を取得した後、ffmpegを起動せず元ファイルをコピーします。
- HDR、8bit超、映像なし、変換が必要な字幕、強制字幕、添付ファイル、未対応データストリームなど、保持条件を満たせない入力は元ファイルを維持します。
- MP4出力時の `tmcd` / `mebx` データストリーム削除は許容し、CSVの備考に記録します。
- 検証済みかつ元より小さい結果のみMP4として配置します。保持不可・サイズ削減なしの場合は、ミラー設定に関係なく元の拡張子でコピーします。通常の処理失敗時のコピーはミラー設定に従います。
- 出力名の衝突を解消し、再実行時も同じ名前を使用します。

### UI・ジョブ管理

- 「圧縮設定」「出力設定」「アプリ設定」「ログ・進捗」の4タブ構成に変更しました。
- 動画の処理段階・進捗表示と停止ボタンを追加しました。停止・終了時は実行中の処理の終了を待ち、配置済みの結果を残します。
- ジョブは同時に1件、動画エンコードは同時に1件です。画像・PDF処理には別ワーカーを使用します。CPU使用率の上限は保証しません。
- 二重開始と処理中のクリーンアップを防止します。別インスタンスも含め、同じ出力フォルダへの圧縮・出力クリーンアップを排他制御します。
- ロック・動画作業用の `.pjp_work/` は出力クリーンアップの対象外です。
- 日英UI、ログ、CSVに動画関連の表示を追加しました。

## 重要な動作上の注意

- **入力クリーンアップは、動画圧縮設定の有効・無効に関係なく、対象フォルダとサブフォルダの動画ファイルも取り消し不可で削除します。** 実行前に対象を確認してください。
- PATH上のsystem ffmpeg / ffprobeを優先し、未検出時は承認済みの同梱版へフォールバックします。system版の構成は同梱版と異なる場合があります。検出結果の更新にはアプリの再起動が必要です。
- MP4に格納できる音声でも、すべての再生機器での互換性は保証しません。
- 同名の既存出力は上書きします。前回MP4を出力し、次回は元のMOVなどを維持した場合、前回のMP4は自動削除されません。
- FFmpeg / ffprobeが利用できない場合は動画機能を無効化し、PDF・画像機能は継続します。

FFmpegは任意の外部メディアライブラリをx264に限定し、x265を含めず、HEVC encoder・decoder・parser等を無効化した構成です。一般的なFFmpeg内部codec・filter・コンテナ機能は残しており、全機能を絞った最小構成ではありません。gyan.dev full buildは使用・同梱しません。

2026年11月2日のプロジェクト上の再配布承認は、[配布マニフェスト](https://github.com/sho-kawasaki-dd/pjp_compressor_v2/blob/v2.7.0/Documentation/ffmpeg-x264-only-manifest.json)に記載したバイナリ・ソース・ライセンス表示・ビルド情報に限定されます。PyInstallerの梱包時に、同梱FFmpegバイナリと必須ライセンス表示のSHA256を照合します。

FFmpegとx264の採用ソースにはパッチを適用していません。x264の全270ファイルは上記の上流コミットとバイト単位で一致しています。詳細は[配布物の調査記録](https://github.com/sho-kawasaki-dd/pjp_compressor_v2/blob/v2.7.0/Documentation/ffmpeg-distribution-audit.md)と[ビルドスクリプト](https://github.com/sho-kawasaki-dd/pjp_compressor_v2/blob/v2.7.0/scripts/build_ffmpeg_x264.sh)を参照してください。
